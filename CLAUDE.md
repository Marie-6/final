# Lost Traveler (迷子の旅人)

A first-person 3D walk through a Tokyo-style street that teaches beginner Japanese. three.js 0.160 from a CDN, no framework, no bundler.

**Main track: `lost-traveler/firstperson/`.** `prototype/` is the older Day 1 slice and `research/` is the research site: don't open them unless I ask. `docs/architecture.md` describes `prototype/`, not firstperson.

## Run

The live-refresh server serves `lost-traveler/` on port 8000.
- Game: http://localhost:8000/firstperson/?debug (`?debug` exposes `player`, `TRAIN`, `STA`, `floorAt`, `blocked` on `window`)
- Other URL params: `ui=0` hides the UI for screenshots, `t=asa|hiru|yoru` sets the time of day, `cam=...` sets the camera

## How the code is laid out

- `firstperson/src/*.js`: the game code, split into sections. **Edit these.**
- `firstperson/game.js`: GENERATED by joining `src/` in file-name order. **Never read or edit it.** A hook rebuilds it after every edit. To rebuild by hand: `node lost-traveler/firstperson/build.mjs`
- All `src/` files share ONE scope (they are joined, not imported), so a function defined in one file can be used in any later file. Order matters: define helpers in earlier-numbered files.
- A browser error at `game.js:1234` → run `node lost-traveler/firstperson/build.mjs --where 1234` to get the src file and line.
- New file: pick a number between its neighbours (e.g. `215-station-signs.js`) so it lands in the right place.

## Adding new content

- One thing per file (one place, one system, one interaction). New content goes in NEW files, never appended to existing ones.
- New scene or walk-in place (e.g. konbini, park): `XXX-<name>-textures.js` + `XXX-build-<name>.js`, numbered before 260. Then add ONE line in `260-build-everything.js` to call it.
- New interaction (e.g. buying at the konbini): `XXX-<name>-interaction.js`, numbered between 330 and 370. Only add a short hook in shared files.
- Split a file when it grows past ~600 lines, along a natural boundary (e.g. textures vs. building). Never cut a single function in half just to hit a number.
- Before creating files, tell me the new file name(s) and which shared files get a one-line hook.

## Working rules (save tokens)

1. Find code with `grep -n` across `src/` first, then read only the lines you need (`sed -n` or a ranged Read). Never read a whole folder.
2. Only open the files the task touches. A café change should not read the station files.
3. Never read: `game.js`, `firstperson-backup/`, `*.png`, `*.jpg`, `*.ttf`, `index.html` beyond the HTML/CSS you need.
4. Small, targeted edits. Don't rewrite whole files or reformat code you aren't changing.
5. Ask before big restructures or before touching more than ~3 files.

## Check your change

Reload http://localhost:8000/firstperson/?debug: no new console errors, then walk to what you changed.
